# Research & Notes

The foundation's working research corpus — independent of the website. The site
(`../site/`) distills from these docs but never edits them; the site's own
planning docs (`../WEBSITE_OUTLINE.md`, `../COPY_VOICE_GUIDE.md`, `../HOME.md`)
live at the repo root.
