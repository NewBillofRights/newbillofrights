# Logo samples (2026-08-17)

Four directions generated from the brand tokens by `scripts/make-logo-samples.mjs`.
Each has an SVG (vector, text outlined) and a PNG. `contact-sheet.png` shows all four.

- **A-wordmark** — A — Typographic wordmark (the current identity, formalized)
- **B-monogram-seal** — B — Monogram seal (N with the gold mark) + stacked wordmark
- **C-bill-mark** — C — The bill mark (document with gold seal) + wordmark
- **D-reverse-band** — D — Reverse (ink ground) with a numbered-article motif
