# Social media

Response plans, post drafts, and channel notes for the foundation's public
voice outside the site. One file per moment or campaign, dated.

Rules carried over from the site (COPY_VOICE_GUIDE.md, research/MISSION.md):

- Research institution, not advocacy campaign. Evidence first; never exhort.
- Nonpartisan discipline: never name a current or recent officeholder; never
  cite one side's abuses without the other's; no left/right-coded vocabulary.
- Every poll number carries party split, pollster, and year — and must already
  exist in the research corpus or on the site. Never invent a URL or a number.
- Final public copy gets a Gemini Pro pass before it is posted
  (`scripts/gemini-review.sh`), and every Gemini factual claim is web-verified.
- Sign as "Founder, New Bill of Rights Foundation" / michael@newbillofrights.net.
